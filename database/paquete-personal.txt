#
# Es la única lista. La usan:
#   - database/aplicar-paquete-personal.sh  (el comando que se corre allá y acá)
#   - make reset / make paquete             (local)
#   - deploy/migrate.sh                     (nuestra VM)
#
# Una ruta por línea, relativa a esta carpeta (database/). Cada script tiene que:

#   - agregar columnas en tablas de ellos solo nullable o con default,
#   - ir dentro de BEGIN ... COMMIT.
#
# NO van acá: seed_demo.sql ni nada que cargue datos de demo.
